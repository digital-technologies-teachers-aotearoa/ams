# Your website

**Who this page is for:** client website admins — the volunteers who set up and run your association's AMS site.

This section covers everything about running your website day to day, split into two groups:

- **[Setup guide](setup/index.md)** — an ordered, step-by-step path from an empty, freshly-provisioned site to a published, branded website ready to launch.
  Work through it once, in order, when you're setting up for the first time.
- **[Feature reference](reference/index.md)** — a standing reference for every feature (CMS, events, resources, forum, billing, theme customization), organised by topic rather than by order.
  Come back here whenever you need to look up a detail the setup guide didn't cover in full, or need a refresher on something you set up a while ago.

If you're setting up your site for the first time, start with the Setup guide.
